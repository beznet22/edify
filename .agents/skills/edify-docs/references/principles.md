# Principles

Principles referenced throughout Edify docs. Full definitions and rationale live in `docs/vision/principles.md`. This file is a quick pointer for skill users.

The 8 canonical principles:

1. **Ministry First** — technology serves ministry, never the reverse
2. **Local-First** — every device is a fully functional ministry workstation; the cloud enhances but never enables core functionality
3. **Serverless by Design** — computation scales with users adding devices; the cloud coordinates, devices execute
4. **Cloud-Managed** — the cloud provides identity, organizations, licensing, marketplace, sync, notifications, public APIs
5. **Peer-to-Peer Collaboration** — devices communicate directly when possible; cloud relay only when direct fails
6. **Deterministic Before Generative** — critical paths are deterministic, explainable, offline; AI agents enhance asynchronously
7. **Knowledge-Centric** — knowledge, not documents, is the platform's primary asset
8. **Event-Driven** — subsystems communicate through strongly typed events on a shared Event Bus

For the full text of each principle (with rationale, what it forbids, and concrete examples), see `docs/vision/principles.md`.
